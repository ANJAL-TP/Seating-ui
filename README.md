# Seating-ui
# Automatic Exam Seating Arrangement System

## Problem
Manual seating arrangement in colleges takes time and may cause conflicts.

## Solution
This system automatically generates seating arrangements based on constraints.

## Features
- CSV student upload
- Hall capacity management
- Automatic seating allocation
- Dashboard UI
- Download seating plan

## Tech Stack
Frontend: HTML, CSS, JavaScript
Backend: Django
Database: SQLite/PostgreSQL

## Algorithm
Ensures not more than 4 students of same course in a hall.

## How to Run
1. Clone repo
2. Install dependencies
3. Run Django server
